# Website SD Muhammadiyah 1 Wonogiri (scaffold v0.1)
Astro 5 + Tailwind v4. `npm install && npm run dev`. Deploy: push ke `main` (butuh secret CLOUDFLARE_API_TOKEN dan CLOUDFLARE_ACCOUNT_ID).
Isi yang masih menunggu data sekolah: cari `TODO` di `src/data/site.ts` dan `astro.config.mjs`, serta teks "menunggu data" di `src/pages/`.
Berita: tambah file .md di `src/content/berita/`.
